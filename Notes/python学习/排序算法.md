# 十大排序算法

## 一、冒泡排序

时间复杂度：* 最坏情况：O(n²)

* 最好情况：O(n) - 优化版本
* 平均情况：O(n²)

空间复杂度： O(1) - 原地排序

稳定性： 稳定排序算法

#### 算法原理

1. 比较相邻元素：从第一个元素开始，依次比较相邻的两个元素
2. 交换位置：如果前一个元素大于后一个元素，则交换它们的位置
3. 重复遍历：重复上述过程，直到没有需要交换的元素
4. 优化策略：如果某一轮没有发生交换，说明数组已经有序，可以提前退出

```python
def bubble_sort(arr):
    """
    冒泡排序算法实现
  
    Args:
        arr: 需要排序的列表
    
    Returns:
        排序后的列表
    """
    n = len(arr)
  
    # 外层循环控制排序轮数
    for i in range(n):
        # 内层循环进行相邻元素比较和交换
        # 每轮排序后，最大的元素会"冒泡"到末尾
        # 因此每轮可以少比较一个元素
        for j in range(0, n - i - 1):
            # 如果前一个元素大于后一个元素，则交换它们
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
  
    return arr


def bubble_sort_optimized(arr):
    """
    优化版本的冒泡排序算法
  
    优化点：如果某一轮没有发生交换，说明数组已经有序，可以提前退出
  
    Args:
        arr: 需要排序的列表
    
    Returns:
        排序后的列表
    """
    n = len(arr)
  
    for i in range(n):
        # 标记本轮是否发生交换
        swapped = False
    
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
    
        # 如果没有发生交换，说明数组已经有序，提前退出
        if not swapped:
            break
  
    return arr
```

## 二、选择排序


#### 算法特点

时间复杂度：* 最坏情况：O(n²)

* 最好情况：O(n²)
* 平均情况：O(n²)

空间复杂度： O(1) - 原地排序

稳定性： 不稳定排序算法（相同元素的相对位置可能改变）

#### 算法原理

1. 初始化：将整个数组分为已排序区间（空）和未排序区间（整个数组）
2. 寻找最小元素：在未排序区间中找到最小的元素
3. 交换位置：将找到的最小元素与未排序区间的第一个元素交换
4. 扩展已排序区间：将交换后的元素纳入已排序区间
5. 重复过程：重复步骤2-4，直到未排序区间为空

```python
def selection_sort(arr):
    """
    选择排序算法实现
  
    算法思想：
    1. 在未排序序列中找到最小元素
    2. 将其与未排序序列的第一个元素交换位置
    3. 重复上述过程，直到所有元素排序完成
  
    Args:
        arr: 需要排序的列表
  
    Returns:
        排序后的列表
    """
    n = len(arr)
  
    # 外层循环控制已排序区间的边界
    for i in range(n):
        # 找到未排序区间中最小元素的索引
        min_idx = i
  
        # 在未排序区间中寻找最小元素
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
  
        # 将找到的最小元素与未排序区间的第一个元素交换
        if min_idx != i:
            arr[i], arr[min_idx] = arr[min_idx], arr[i]
  
    return arr

    """
    降序选择排序算法实现
  
    Args:
        arr: 需要排序的列表
  
    Returns:
        降序排序后的列表
    """
    n = len(arr)

        max_idx = i
  
        for j in range(i + 1, n):
            if arr[j] > arr[max_idx]:
                max_idx = j
  
        # 将找到的最大元素与未排序区间的第一个元素交换
        if max_idx != i:
            arr[i], arr[max_idx] = arr[max_idx], arr[i]
  
    return arr

        print(f"        当前状态: {arr}")
        print("-" * 40)
  
    return arr
```

## 三、插入排序


#### 算法特点

时间复杂度：* 最坏情况：O(n²) - 数组完全逆序

* 最好情况：O(n) - 数组已经有序
* 平均情况：O(n²)

空间复杂度： O(1) - 原地排序

稳定性： 稳定排序算法

#### 算法原理

1. 初始化：将第一个元素视为已排序序列
2. 取元素：从未排序序列中取出第一个元素
3. 查找位置：在已排序序列中从后向前查找该元素的插入位置
4. 移动元素：将比该元素大的所有元素向后移动一位
5. 插入元素：将该元素插入到找到的位置
6. 重复过程：重复步骤2-5，直到所有元素都插入完成

```python
def insertion_sort(arr):
    """
    插入排序算法实现
  
    算法思想：
    1. 将第一个元素视为已排序序列
    2. 从第二个元素开始，逐个将元素插入到已排序序列的合适位置
    3. 通过比较和移动元素，保持已排序序列的有序性
  
    Args:
        arr: 需要排序的列表
    
    Returns:
        排序后的列表
    """
    n = len(arr)
  
    # 从第二个元素开始遍历（索引1）
    for i in range(1, n):
        # 当前要插入的元素
        current = arr[i]
        # 从已排序序列的末尾开始向前查找插入位置
        j = i - 1
    
        # 将比current大的元素都向后移动一位
        while j >= 0 and arr[j] > current:
            arr[j + 1] = arr[j]
            j -= 1
    
        # 找到插入位置，将current插入
        arr[j + 1] = current
  
    return arr

        arr[j + 1] = current
    
        print(f"        插入后: {arr}")
        print("-" * 40)
  
    return arr


def insertion_sort_optimized(arr):
    """
    优化版本的插入排序算法
  
    优化点：使用二分查找来找到插入位置，减少比较次数
  
    Args:
        arr: 需要排序的列表
    
    Returns:
        排序后的列表
    """
    def binary_search(arr, target, start, end):
        """二分查找插入位置"""
        while start < end:
            mid = (start + end) // 2
            if arr[mid] <= target:
                start = mid + 1
            else:
                end = mid
        return start
  
    n = len(arr)
  
    for i in range(1, n):
        current = arr[i]
        # 使用二分查找找到插入位置
        insert_pos = binary_search(arr, current, 0, i)
    
        # 移动元素
        for j in range(i, insert_pos, -1):
            arr[j] = arr[j - 1]
    
        # 插入元素
        arr[insert_pos] = current
  
    return arr


def insertion_sort_recursive(arr, n=None):
    """
    递归版本的插入排序算法
  
    Args:
        arr: 需要排序的列表
        n: 当前要排序的元素个数
    
    Returns:
        排序后的列表
    """
    if n is None:
        n = len(arr)
  
    # 基本情况：只有一个元素时已经有序
    if n <= 1:
        return arr
  
    # 递归排序前n-1个元素
    insertion_sort_recursive(arr, n - 1)
  
    # 将第n个元素插入到已排序的前n-1个元素中
    current = arr[n - 1]
    j = n - 2
  
    while j >= 0 and arr[j] > current:
        arr[j + 1] = arr[j]
        j -= 1
  
    arr[j + 1] = current
  
    return arr
```

## 四、快速排序

#### 算法特点

时间复杂度：* 平均情况：O(n log n)

* 最坏情况：O(n²) - 当数组已经有序或逆序时
* 最好情况：O(n log n)

空间复杂度：* 平均情况：O(log n) - 递归调用栈的深度

* 最坏情况：O(n) - 当数组已经有序时

稳定性： 不稳定排序算法

#### 算法原理

1. 选择基准：从数组中选择一个基准元素
2. 分区：将数组分成两部分，左边都小于基准，右边都大于基准
3. 递归排序：递归地对左右两部分进行排序
4. 合并：由于分区操作已经保证了相对顺序，直接合并即可

```python
def quick_sort(arr):
    """
    快速排序算法实现
  
    算法思想：
    1. 选择一个基准元素（pivot）
    2. 将数组分成两部分：小于基准的元素和大于基准的元素
    3. 递归地对这两部分进行排序
    4. 合并结果
  
    Args:
        arr: 需要排序的列表
    
    Returns:
        排序后的列表
    """
    if len(arr) <= 1:
        return arr
  
    # 选择基准元素（这里选择最后一个元素）
    pivot = arr[-1]
  
    # 分区：将数组分成小于pivot和大于pivot的两部分
    left = [x for x in arr[:-1] if x <= pivot]
    right = [x for x in arr[:-1] if x > pivot]
  
    # 递归排序并合并结果
    return quick_sort(left) + [pivot] + quick_sort(right)


def quick_sort_inplace(arr, low=None, high=None):
    """
    原地快速排序算法实现
  
    这种实现方式不需要额外的存储空间，直接在原数组上操作
  
    Args:
        arr: 需要排序的列表
        low: 排序区间的起始索引
        high: 排序区间的结束索引
    
    Returns:
        排序后的列表
    """
    if low is None:
        low = 0
    if high is None:
        high = len(arr) - 1
  
    if low < high:
        # 分区并获取基准元素的最终位置
        pivot_index = partition(arr, low, high)
    
        # 递归排序基准元素左边的部分
        quick_sort_inplace(arr, low, pivot_index - 1)
        # 递归排序基准元素右边的部分
        quick_sort_inplace(arr, pivot_index + 1, high)
  
    return arr


def partition(arr, low, high):
    """
    分区函数：将数组分成两部分，返回基准元素的最终位置
  
    Args:
        arr: 需要分区的列表
        low: 分区区间的起始索引
        high: 分区区间的结束索引
    
    Returns:
        基准元素的最终位置
    """
    # 选择最右边的元素作为基准
    pivot = arr[high]
  
    # i指向小于基准元素的最后一个位置
    i = low - 1
  
    # 遍历数组，将小于基准的元素移到左边
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
  
    # 将基准元素放到正确的位置
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
  
    return i + 1


def quick_sort_median_of_three(arr, low=None, high=None):
    """
    使用三数取中法选择基准的快速排序
  
    这种方法通过选择三个元素的中位数作为基准，可以减少最坏情况的概率
  
    Args:
        arr: 需要排序的列表
        low: 排序区间的起始索引
        high: 排序区间的结束索引
    
    Returns:
        排序后的列表
    """
    if low is None:
        low = 0
    if high is None:
        high = len(arr) - 1
  
    if low < high:
        # 使用三数取中法选择基准
        pivot_index = median_of_three_partition(arr, low, high)
    
        # 递归排序
        quick_sort_median_of_three(arr, low, pivot_index - 1)
        quick_sort_median_of_three(arr, pivot_index + 1, high)
  
    return arr


def median_of_three_partition(arr, low, high):
    """
    三数取中法分区函数
  
    Args:
        arr: 需要分区的列表
        low: 分区区间的起始索引
        high: 分区区间的结束索引
    
    Returns:
        基准元素的最终位置
    """
    # 计算中间位置
    mid = (low + high) // 2
  
    # 将三个位置的元素排序
    if arr[low] > arr[mid]:
        arr[low], arr[mid] = arr[mid], arr[low]
    if arr[low] > arr[high]:
        arr[low], arr[high] = arr[high], arr[low]
    if arr[mid] > arr[high]:
        arr[mid], arr[high] = arr[high], arr[mid]
  
    # 将中位数放到倒数第二个位置
    arr[mid], arr[high - 1] = arr[high - 1], arr[mid]
  
    # 选择中位数作为基准
    pivot = arr[high - 1]
  
    # 分区过程
    i = low
    j = high - 1
  
    while True:
        # 从左向右找到大于等于基准的元素
        i += 1
        while arr[i] < pivot:
            i += 1
    
        # 从右向左找到小于等于基准的元素
        j -= 1
        while arr[j] > pivot:
            j -= 1
    
        # 如果两个指针相遇，分区完成
        if i >= j:
            break
    
        # 交换元素
        arr[i], arr[j] = arr[j], arr[i]
  
    # 将基准元素放到正确的位置
    arr[i], arr[high - 1] = arr[high - 1], arr[i]
  
    return i


def quick_sort_with_trace(arr, low=None, high=None, depth=0):
    """
    带跟踪信息的快速排序算法实现
  
    Args:
        arr: 需要排序的列表
        low: 排序区间的起始索引
        high: 排序区间的结束索引
        depth: 递归深度
    
    Returns:
        排序后的列表
    """
    if low is None:
        low = 0
    if high is None:
        high = len(arr) - 1
  
    indent = "  " * depth
    print(f"{indent}深度 {depth}: 排序区间 [{low}, {high}], 数组: {arr[low:high+1]}")
  
    if low < high:
        # 分区
        pivot_index = partition(arr, low, high)
        print(f"{indent}基准元素位置: {pivot_index}, 值: {arr[pivot_index]}")
    
        # 递归排序左边
        quick_sort_with_trace(arr, low, pivot_index - 1, depth + 1)
        # 递归排序右边
        quick_sort_with_trace(arr, pivot_index + 1, high, depth + 1)
  
    return arr
```

## 五、归并排序

#### 算法原理

1. 分解：将数组分成两半
2. 解决：递归地对两半进行排序
3. 合并：将两个有序数组合并成一个有序数组

#### 算法优势

* 稳定：相同元素的相对位置不会改变
* 时间复杂度稳定：无论输入如何，时间复杂度都是O(n log n)
* 适合外部排序：可以处理无法全部加载到内存的数据

```python
def merge_sort(arr):
    """
    归并排序算法实现
  
    算法思想：
    1. 将数组分成两半
    2. 递归地对两半进行排序
    3. 将两个有序数组合并成一个有序数组
  
    Args:
        arr: 需要排序的列表
    
    Returns:
        排序后的列表
    """
    # 基本情况：数组长度小于等于1时已经有序
    if len(arr) <= 1:
        return arr
  
    # 将数组分成两半
    mid = len(arr) // 2
    left = arr[:mid]
    right = arr[mid:]
  
    # 递归排序两半
    left_sorted = merge_sort(left)
    right_sorted = merge_sort(right)
  
    # 合并两个有序数组
    return merge(left_sorted, right_sorted)


def merge(left, right):
    """
    合并两个有序数组
  
    Args:
        left: 左半部分的有序数组
        right: 右半部分的有序数组
    
    Returns:
        合并后的有序数组
    """
    result = []
    i = j = 0
  
    # 比较两个数组的元素，将较小的元素添加到结果中
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
  
    # 添加剩余的元素
    result.extend(left[i:])
    result.extend(right[j:])
  
    return result


def merge_sort_inplace(arr, left=None, right=None, temp=None):
    """
    原地归并排序算法实现
  
    这种实现方式不需要额外的存储空间来存储子数组，但需要额外的空间来存储合并结果
  
    Args:
        arr: 需要排序的列表
        left: 排序区间的起始索引
        right: 排序区间的结束索引
        temp: 临时数组，用于存储合并结果
    
    Returns:
        排序后的列表
    """
    if left is None:
        left = 0
    if right is None:
        right = len(arr) - 1
    if temp is None:
        temp = [0] * len(arr)
  
    if left < right:
        mid = (left + right) // 2
    
        # 递归排序左半部分
        merge_sort_inplace(arr, left, mid, temp)
        # 递归排序右半部分
        merge_sort_inplace(arr, mid + 1, right, temp)
    
        # 合并两个有序部分
        merge_inplace(arr, left, mid, right, temp)
  
    return arr


def merge_inplace(arr, left, mid, right, temp):
    """
    原地合并两个有序数组
  
    Args:
        arr: 需要合并的数组
        left: 左半部分的起始索引
        mid: 左半部分的结束索引
        right: 右半部分的结束索引
        temp: 临时数组
    """
    i = left      # 左半部分的起始索引
    j = mid + 1   # 右半部分的起始索引
    k = left      # 临时数组的索引
  
    # 比较两个部分的元素，将较小的元素放入临时数组
    while i <= mid and j <= right:
        if arr[i] <= arr[j]:
            temp[k] = arr[i]
            i += 1
        else:
            temp[k] = arr[j]
            j += 1
        k += 1
  
    # 添加剩余的元素
    while i <= mid:
        temp[k] = arr[i]
        i += 1
        k += 1
  
    while j <= right:
        temp[k] = arr[j]
        j += 1
        k += 1
  
    # 将临时数组的结果复制回原数组
    for i in range(left, right + 1):
        arr[i] = temp[i]


def merge_sort_bottom_up(arr):
    """
    自底向上的归并排序算法实现
  
    这种实现方式避免了递归调用，使用迭代的方式实现
  
    Args:
        arr: 需要排序的列表
    
    Returns:
        排序后的列表
    """
    n = len(arr)
    temp = [0] * n
  
    # 从1开始，每次将相邻的两个长度为size的子数组合并
    size = 1
    while size < n:
        # 遍历所有可能的子数组对
        for left in range(0, n - size, 2 * size):
            mid = left + size - 1
            right = min(left + 2 * size - 1, n - 1)
        
            # 合并两个子数组
            merge_inplace(arr, left, mid, right, temp)
    
        size *= 2
  
    return arr


def merge_sort_with_trace(arr, left=None, right=None, depth=0):
    """
    带跟踪信息的归并排序算法实现
  
    Args:
        arr: 需要排序的列表
        left: 排序区间的起始索引
        right: 排序区间的结束索引
        depth: 递归深度
    
    Returns:
        排序后的列表
    """
    if left is None:
        left = 0
    if right is None:
        right = len(arr) - 1
  
    indent = "  " * depth
    print(f"{indent}深度 {depth}: 排序区间 [{left}, {right}], 数组: {arr[left:right+1]}")
  
    if left < right:
        mid = (left + right) // 2
    
        # 递归排序左半部分
        merge_sort_with_trace(arr, left, mid, depth + 1)
        # 递归排序右半部分
        merge_sort_with_trace(arr, mid + 1, right, depth + 1)
    
        # 合并两个有序部分
        print(f"{indent}合并区间 [{left}, {mid}] 和 [{mid+1}, {right}]")
        merge_inplace(arr, left, mid, right, [0] * len(arr))
        print(f"{indent}合并后: {arr[left:right+1]}")
  
    return arr


def merge_sort_optimized(arr):
    """
    优化版本的归并排序算法
  
    优化点：
    1. 对于小规模数组使用插入排序
    2. 如果左半部分的最大值小于等于右半部分的最小值，则不需要合并
  
    Args:
        arr: 需要排序的列表
    
    Returns:
        排序后的列表
    """
    def insertion_sort(arr, left, right):
        """插入排序，用于小规模数组"""
        for i in range(left + 1, right + 1):
            key = arr[i]
            j = i - 1
            while j >= left and arr[j] > key:
                arr[j + 1] = arr[j]
                j -= 1
            arr[j + 1] = key
  
    def merge_sort_recursive(arr, left, right, temp):
        if right - left + 1 <= 10:  # 小规模数组使用插入排序
            insertion_sort(arr, left, right)
            return
    
        mid = (left + right) // 2
    
        # 递归排序
        merge_sort_recursive(arr, left, mid, temp)
        merge_sort_recursive(arr, mid + 1, right, temp)
    
        # 优化：如果左半部分的最大值小于等于右半部分的最小值，则不需要合并
        if arr[mid] <= arr[mid + 1]:
            return
    
        # 合并
        merge_inplace(arr, left, mid, right, temp)
  
    temp = [0] * len(arr)
    merge_sort_recursive(arr, 0, len(arr) - 1, temp)
    return arr
```
